# v1.8.3 — 接入 Interactive Brokers（TWS / IB Gateway）

- **交易员可以在 IBKR 账户里执行。** 交易员「设置」里新增「执行方式」：美股交易员可以改成在 设置 → 券商连接 里配置的 IBKR 账户下单，不走内置模拟撮合。交易员的各种下单（Agent、代码策略、你的确认、止损止盈、回撤减仓）都在美股常规时段经 IBKR 护栏发出，只有 IB 回报成交才记账；后台大约每 90 秒和 IB 核对一次，交易员页面显示 IB 现金和账本差额。已在 TWS 模拟账户实测买卖。
- **IBKR 连接**（设置 → 券商连接 → Interactive Brokers）：模拟账户（DU…）里 Agent 在你设的白名单/限额内自己下单，可以选「允许任意美股」；实盘账户（U…）里 Agent 只能提议，每一笔都要你在首页确认才发出。只做多、只用现金、当日限价单。`npm run setup:ibkr` 安装固定版本的 `ib_async`。说明见 docs/BROKER_IBKR.md。
- 针对真实 TWS 的修正：演示系统的短账户号、TWS 不返回已完成委托时改用当日成交、TWS 拒单原因直接显示（比如 API 只读）、IB 没收到的单可以手动解除阻塞。
- 其他：市场雷达加了港股、美股（1.8.2）；自动更新下载超时放宽到 10 分钟；Windows 测试偶发失败修复。

In English: US traders can execute in an Interactive Brokers account (TWS / IB Gateway) instead of the built-in simulator — paper orders within your limits, live orders only after you confirm each one; fills come from IB executions. See docs/BROKER_IBKR.md.
