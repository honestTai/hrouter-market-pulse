# CANSLIM 成长股

> 方法来自 tradermonty/claude-trading-skills 的 canslim-screener（MIT），依据欧奈尔的 CANSLIM。原技能用 FMP / Finviz 数据，这里改用工作台的行情、扫描和官方财务证据。

七个要素，每个打 0–100 分，按权重合成总分；**大盘方向（M）不对时一律不开新仓**。

| 要素 | 含义 | 用什么查 |
|---|---|---|
| C 当季盈利 | 最近一季 EPS 同比增长 ≥ 25%，最好加速 | `query_evidence`、`build_earnings_review` |
| A 年度盈利 | 近三年 EPS 年增长 ≥ 25%，ROE ≥ 17% | 同上 |
| N 新事物 | 新产品、新管理层、新高：股价在 52 周高点 15% 以内 | `ctx.history` / `get_quote` |
| S 供需 | 上涨日放量、下跌日缩量（上涨量 / 下跌量 > 1） | 日线成交量 |
| L 龙头 | 相对强度：3 / 6 / 12 个月涨幅跑赢基准，排在前 20% | 日线 + 基准 |
| I 机构 | 有机构持续增持（美股 SEC 13F 证据，可得时） | `query_evidence` |
| M 大盘 | 基准在 50 日均线上方且趋势向上 | 基准日线 |

分级：90+ 可积极买入，80–89 强，70–79 标准买入，60–69 回调再买，低于 60 不碰。拿不到的要素（例如港股机构持仓）给中性 50 分并在理由里说明，不要编数据。入场在突破有效的买点附近，止损 7–8%，跌破 50 日线离场。
