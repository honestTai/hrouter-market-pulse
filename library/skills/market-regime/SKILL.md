# 宏观择时与市场状态

> HRouter 原创（honestTai/hrouter-market-pulse），结合 tradermonty/claude-trading-skills 的 exposure-coach（MIT）思路：先判断市场状态，再决定总仓位，个股选择放在后面。所有读数都来自工作台的真实数据工具，取不到的就写取不到。

## 读数

| 市场 | 工具 | 看什么 |
|---|---|---|
| A 股 | `get_market_radar` | 两市涨跌家数和成交额、涨停 / 炸板 / 跌停、主线板块 |
| A 股 | `get_margin` | 融资余额连续升降、融资净买入（杠杆资金情绪，次日早上公布前一日） |
| A 股 / 港股 | `get_stock_connect` | 北向成交额（2024 年 8 月起不公布净买入）、南向成交和净买入 |
| 全部 | `get_quote` + `run_strategy` / 日线 | 指数（000300.SS、^HSI、^GSPC、^IXIC）与 50 / 200 日均线的位置、^VIX 水平 |

## 状态和总仓位

| 状态 | 判定（满足多数） | 建议总仓位 |
|---|---|---|
| 进攻 | 指数在 50 日线上且 50 日线向上；上涨家数持续多于下跌；融资余额回升；VIX < 18 | 70–90% |
| 中性 | 指数在 50 日线附近震荡；涨跌家数互有胜负 | 40–60% |
| 防守 | 指数跌破 50 日线；下跌家数连续多于上涨；融资余额连续下降；VIX 18–25 | 20–40% |
| 避险 | 指数跌破 200 日线或放量下跌；炸板率高、跌停扩散；VIX > 25 | 0–20% |

总仓位不能超过硬性边界里的「总仓位上限」，也要满足「保留现金」。状态变化时用 `arena_set_limits` 调整自己的总仓位上限（没被锁定时），并在报告里写明依据；被锁定的会变成申请等主人确认。

## 节奏

- 每天第一次复查先定状态，状态没变就不动总仓位；
- 状态降级当天执行减仓，升级要连续两天确认再加仓；
- 换状态的理由写进 `arena_log_decision`，附上用到的读数和日期。

## 和个股决策的关系

状态只决定「最多拿多少仓位」。具体买什么交给投资人评审或你的其他流派 skill；防守和避险状态下只保留最强的持仓，新开仓门槛提高。
