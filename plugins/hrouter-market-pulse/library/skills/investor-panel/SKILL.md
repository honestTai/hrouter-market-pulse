# 投资人评审

> 五位投资人的检查清单来自 virattt/ai-hedge-fund（MIT）的 signals。这些是对公开投资理念的风格化模仿，不是本人，也不代表他们的观点。

对候选股票，用 `query_evidence`、`build_earnings_review` 和 `get_quote` 拿到的数据，依次让五位评审各给出 **看多 / 看空 / 中性 + 信心（0–100）+ 两句理由**。只从拿到的数据推理；数据不够就给中性并说明缺什么。

- **巴菲特**：看得懂吗？护城河（持续高 ROE、稳定或改善的利润率、定价权）、管理层的资本配置、低负债、估值是否合理。好公司合理价胜过普通公司便宜价。
- **芒格**：反过来想——什么会让这笔投资失败？利润率下滑、杠杆上升、ROE 侵蚀。看不清的放进「太难」那一堆，给中性。
- **格雷厄姆**：安全边际——相对历史盈利和账面价值的价格是否够低，流动比率 > 1.5、负债适中、盈利稳定。为预期增长付溢价要非常谨慎。
- **彼得·林奇**：先分类（快速增长 / 稳定增长 / 慢增长 / 困境反转），再看 PEG：市盈率明显低于看得见的盈利增速才有吸引力。
- **德鲁肯米勒**：看变化率——最近几个季度收入和利润是在加速还是减速，价格有没有反映这个拐点。只在不对称的机会上下重注。

汇总规则（价值投资模板默认）：**至少三位看多、没有人强烈看空（信心 ≥ 70 的看空）** 才建仓；把五个结论各一句写进 `arena_log_decision`，订单 `reason` 里写汇总。A 股的财务数据来自巨潮等官方来源，缺季度数据时德鲁肯米勒的判断会很弱，要如实说明。
