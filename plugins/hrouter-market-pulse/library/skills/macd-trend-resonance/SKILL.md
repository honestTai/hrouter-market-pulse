# 均线定方向 · MACD 定节奏

> 方法来自 shouldnotappearcalm/a-share-skill 的 macd-trend-resonance-stock-picker（MIT）。数据改用工作台的真实日线和分钟线；起始代码策略见 `macd-resonance`。

**第一步，均线定方向（硬过滤）**：

- 60 日线向上且收盘在 60 日线上方 → 趋势合格；
- 60 日线走平或缠绕 → 只观察；
- 60 日线向下且收盘在其下方 → 直接剔除。方向不对，MACD 再好也不进强候选。

**第二步，MACD 定节奏（12 / 26 / 9）**，优先级从高到低：零轴上方金叉；红柱缩短后再放大；DIF 和 DEA 同步向上；60 分钟级别和日线同向。零轴下方的金叉只当反弹。

**四档分级**：

| 档 | 条件 | 动作 |
|---|---|---|
| A | 趋势合格 + 零轴上方金叉或红柱二次放大 + 短周期同步 | 回踩不破或放量突破时执行 |
| B | 趋势合格，MACD 刚回到零轴上方，确认度一般 | 轻仓试错，等突破前高 |
| C | 均线多头但顶背离或死叉；或零轴下方金叉 | 只观察 |
| D | 60 日线向下、持续在其下方、死叉后走弱 | 回避 |

**买点只做可验证的触发**：突破近 5–10 日平台高点、回踩 20 日线不破后再放量。失效条件写在买入前：跌破触发 K 线低点或 20 日线。出现顶背离先减半仓。
