# v1.8.1 — 安装修复

在 1.8.0 的基础上修了三个安装问题，功能和 1.8.0 一样（完整介绍见 [v1.8.0](https://github.com/honestTai/hrouter-market-pulse/releases/tag/v1.8.0)）。

- 本机同时开着很多 Agent 会话、8787–8797 端口都被占时，插件面板改用空闲端口，安装和自动更新的健康检查不再失败。
- macOS 重装常驻服务时会等旧服务退出再启动，不会留下服务停着的状态。
- Windows 桌面客户端可以正常构建（透明标题栏只在 macOS 用）。

## 下载

| 系统 | 文件 |
| --- | --- |
| macOS（Apple 芯片） | `HRouter-Stock-Workbench-1.8.1-macos-arm64.dmg` |
| Windows | `HRouter-Stock-Workbench-1.8.1-windows-x64-setup.exe` |
| Agent 插件 | `hrouter-market-pulse-1.8.1.zip` |

桌面客户端需要 Node.js 20+；安装包没有签名，第一次打开需要在系统里允许。

Fixes in English: the dashboard falls back to a free port when 8787–8797 are taken (installer health checks no longer fail); macOS service reinstalls wait for the old job to unload; the Windows desktop build compiles.
