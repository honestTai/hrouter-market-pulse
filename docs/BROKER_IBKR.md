# Interactive Brokers（TWS / IB Gateway）

通过本机 TWS 或 IB Gateway 交易美股。只做多、只用现金、只下当日限价单（不在盘前盘后成交）。

| 账户 | Agent 能做什么 | 订单怎么发出 |
| --- | --- | --- |
| 模拟账户（DU…） | 在你设的白名单和限额内自己下单、撤单 | Agent 提交即发给 IB |
| 实盘账户（U…） | 只能**提议** | 每一笔都出现在「工作台 → 需要你看」和「设置 → 券商连接」，你点「确认下单」才发出；确认时用最新行情把所有限额再查一遍，超过有效期（默认 10 分钟）自动作废 |

连接设置、账户、白名单、限额、实盘开关、确认和「全部停止」都只能在界面里操作，不是 MCP 工具，Agent 改不了。

## 设置

1. 安装并登录 TWS 或 IB Gateway，**先用模拟账户登录**。
2. TWS：设置 → API → Settings：勾选 *Enable ActiveX and Socket Clients*，取消 *Read-Only API*，*Trusted IPs* 加 `127.0.0.1`。端口：TWS 模拟 7497 / 实盘 7496，IB Gateway 模拟 4002 / 实盘 4001。
3. 在项目目录运行：

   ```bash
   npm run setup:ibkr
   ```

   它在 `~/.local/share/hrouter-market-pulse/ibkr-venv` 建一个独立 venv，装固定版本的 `ib_async==2.1.0`，并离线核对接口签名（不连接、不下单）。需要 Python 3.10+；可以用 `HROUTER_IBKR_PYTHON_BASE` 指定已有的 Python。
4. 工作台 → 设置 → 券商连接 → Interactive Brokers：选端口、保存连接，选「模拟 DU…」，点「连接 TWS」，选账户，填「白名单与限额」。
5. 跑一段时间模拟账户，对过 IB 的委托和成交后，再考虑实盘：在 TWS 用实盘登录，换实盘端口，选「实盘 U…」，在限额对话框里输入「我确认使用真实资金」。

## Agent 工具

| 工具 | 作用 |
| --- | --- |
| `ibkr_get_status` | 连接、你的设置、等你确认的订单、下单记录（不连 TWS） |
| `ibkr_refresh_account` | 从 TWS 读现金、持仓、委托，按 IB 委托号核对本工作台的订单（只读会话） |
| `ibkr_evaluate_order` | 不下单的预检：白名单、限额、新鲜行情、现金、可卖持仓 |
| `ibkr_submit_order` | 模拟账户：下单；实盘账户：只生成待确认提议 |
| `ibkr_cancel_order` | 撤本工作台下的未成交委托 |

## 安全边界

- 只连 `127.0.0.1`。读取用只读 API 会话；凭据只在 TWS 里，本项目不保存密码或 token。
- 模拟和实盘按账户前缀严格分开（DU… / U…），请求的环境和账户对不上就拒绝。
- 每次发单前先把订单意图落盘；结果不明时标成「结果未知」，在核对账户之前不允许新单，也不会换个幂等键重试。
- 买入要求已结算现金覆盖「这笔 + 未成交买单」，卖出要求现有多头持仓减去未成交卖单仍足够；不用融资、不做空。
- 「全部停止」：暂停 Agent、作废所有待确认提议、并请求撤销本工作台所有未成交委托。
- 限制：确认接口是本机 HTTP。工作台拒绝跨站请求，也拒绝带 Agent 标记（交易员回合内）的写请求，但一个能在你电脑上随意执行命令的程序理论上可以绕过。实盘期间不要给 Agent 不受限的 shell 权限。
