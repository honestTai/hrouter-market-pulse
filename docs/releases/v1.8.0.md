# v1.8.0 — 股票工作台：桌面客户端、交易员团队、市场雷达、命令行

上一个正式版是 v1.6.2。这一版把本机多 Agent 股票工作台做完整了（1.7.0 没有单独发布，内容一并在这里）。模拟盘，虚拟资金，不构成投资建议。

## 新东西

- **桌面客户端**（Tauri 2）：打开就是工作台，自动启动本机服务；关掉窗口服务继续跑。
- **交易员**：Agent 当主控，自己写代码策略（沙箱、空跑、回测通过才上线）；边界在下单前强制检查，含单行业上限；锁定和申请；三层前置提示词。
- **自主级别和确认卡片**：全托管 / 关键操作确认 / 只给建议；订单处理流水、引用来源、成交时行情、对账。
- **跟交易员说话**：提问（只读）、指令、长期规则；**团队模式**：只读分析员和多空辩论。
- **复查时机**：没变化不叫醒 Agent，有事提前叫醒；额度用尽换备用，配置错误自动暂停。
- **市场雷达**：A 股涨跌、涨停炸板跌停、连板天梯、情绪周期、龙虎榜和营业部、板块概念、融资、沪深港通；游资短线和宏观择时两个流派。
- **研究任务**：研究问题、个股深度、投资人评审、市场复盘。
- **Skill 库**：14 个内置交易员 skill，可定制、可导入、可检查上游更新。
- **模型选择**：从各 Agent 自己的配置读模型列表，默认最新模型，推理强度默认高。
- **命令行 `market-pulse`**：你和你的 Agent 都能用它操作整个工作台；交易员在自己的复查轮里只能读。
- **即时提醒**：等你确认的订单、回撤熔断、交易员暂停、额度用尽推送到 webhook。
- **英文界面**、面板全屏、手机宽度可用。

## Highlights (English)

Desktop app for macOS and Windows; agent traders that write and backtest their own strategies; hard limits including a per-industry cap; autonomy levels with approval cards; questions, instructions and standing rules; team mode with read-only analysts; change-gated reviews with early wake-ups; an A-share market radar (limit-ups, dragon-tiger list, sentiment cycle, margin, Stock Connect); research tasks including an investor panel; a customizable skill library with imports; model pickers that default to each agent's newest model at high effort; the `market-pulse` CLI; instant webhook alerts; an English UI.
