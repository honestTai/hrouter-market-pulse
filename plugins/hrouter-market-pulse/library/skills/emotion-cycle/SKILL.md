# 情绪周期与题材轮动

> 方法改编自 simonlin1212/vibe-astock 的短线情绪指标（shortline_emotion / shortline_boards，Apache-2.0）：赚钱效应、晋级率、连板梯队、情绪周期。原项目自己抓数，这里全部用工作台的 `get_limit_up_pool` 和 `get_market_radar`，读数来自东方财富涨停板行情，算不出的就如实说算不出。

## 每轮开头先定情绪

调用 `get_limit_up_pool kind=emotion`，读四个数：

| 读数 | 含义 | 冷 | 热 |
|---|---|---|---|
| 晋级率（一进二、二进三…） | 昨天 n 板今天继续封板的比例 | 一进二 < 10% | 一进二 > 30% |
| 赚钱效应 | 昨日涨停股今天的平均涨幅、上涨比例、再涨停只数 | 平均 < −2%，上涨 < 30% | 平均 > +2%，上涨 > 60% |
| 炸板率 | 摸过涨停又打开的比例 | > 40% | < 20% |
| 最高板 / 梯队 | 连板高度，各高度有没有断层 | 最高 ≤ 3 板或断层 | 高度 ≥ 6 板且 3、4 板有梯队 |

再看 `cycle`：情绪分在窗口内的位置（0 = 最冷，1 = 最热）、离最低点几天、最近走向（回暖 / 转弱 / 震荡）。

## 周期阶段和对应打法

| 阶段 | 典型读数 | 能做什么 |
|---|---|---|
| 冰点 | 情绪分接近窗口最低、炸板率高、最高板 ≤ 3 | 空仓或极轻仓；只记录、不接力 |
| 修复 | 离最低点 1–3 天，走向回暖，一进二回升 | 小仓位试新题材的首板、一进二 |
| 发酵 | 情绪分中高位，梯队完整，赚钱效应为正 | 做主线龙头和前排，可以接力 |
| 高潮 | 情绪分接近窗口最高，涨停家数多、高度新高 | 只卖不买新的高位股；兑现为主 |
| 退潮 | 高位转弱，炸板率升，高标断板、补跌 | 不接力；持仓按失效规则离场 |

阶段判断以三项一致为准；三项打架时按更保守的那一档处理。

## 题材轮动

- 用 `get_limit_up_pool kind=sentiment` 的 `hotIndustries` 和 `get_market_radar` 的板块 / 概念涨幅，找当日涨停最集中的方向。
- 主线 = 连续两天以上有涨停集中、且有高度标的方向。只有一天的是脉冲，不当主线。
- 同一方向里只做辨识度最高的（最早封板、最高板、封单最大），跟风股不做。

## 明日验证

报告里写清明天要验证什么：哪几只高标能否晋级、主线是否继续有涨停、炸板率是否回落。下一轮先对照验证结果，再决定是否加仓或撤退。

## 纪律

- 情绪是总开关：冰点和退潮期，任何个股理由都不能推翻「不接力」。
- 数据不全（`moneyEffect` 只取到部分行情、某些日期取不到）时，报告里照实写，不拿不全的数下结论。
