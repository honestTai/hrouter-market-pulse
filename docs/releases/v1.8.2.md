# v1.8.2 — 港股 / 美股市场雷达，复查过程改成侧边栏

- **市场雷达加了港股和美股。** 页面右上角切换 A 股 / 港股 / 美股。港股、美股显示主要指数、全市场涨跌家数、领涨领跌（成交额不足 500 万的不列）、成交最活跃，港股另有南向资金，美股另有中概股。交易员用 `get_market_radar` 传 `market=HK|US` 读到同一份数据。
- **行情源备用。** 东方财富会按 IP 限流、直接断开连接；港股美股雷达这时停用它 5 分钟，指数改从腾讯取、榜单改从新浪取。新浪的港股分页不可靠，所以这种情况下港股涨跌家数显示“暂不可用”，不给错数。
- **交易员页面：复查过程改成侧边栏。** 点时间线或回复里的“看过程”，过程从右侧滑出，不再堆在页面最底下；每次工具调用一行，点开看完整参数和结果，交易员的文字按 Markdown 显示。
