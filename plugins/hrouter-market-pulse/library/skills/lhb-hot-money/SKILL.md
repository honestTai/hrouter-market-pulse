# 龙虎榜与游资席位

> 方法改编自 wbh604/UZI-Skill 的 lhb-analyzer 和 trap-detector（MIT）。原技能用自己的脚本和席位库抓数据，这里只用工作台的真实数据工具：`get_dragon_tiger`（龙虎榜和买卖前五营业部）、`get_limit_up_pool`、`get_quote`、`get_news`。席位名称以交易所公布的营业部全称为准，下面的游资对应关系是公开流传的说法，只作参考，不能当成事实写进报告。

## 什么时候用

- 一只 A 股要不要接力、追涨、低吸之前；
- 持仓股上了龙虎榜，判断次日是延续还是兑现；
- 复盘时解释「谁在买」。

龙虎榜收盘后约 18:00 公布。盘中看到的是前一交易日的榜单，不要当成今天的资金。

## 步骤

1. **看榜**：`get_dragon_tiger`（不带 symbol）拿当日全榜。按净买入排序，记下上榜原因（涨幅偏离 7%、振幅 15%、换手 20%、连续三日偏离等）。
2. **看席位**：对候选股调用 `get_dragon_tiger` 带 `symbol`，拿买卖前五营业部。逐个判断：
   - **机构专用**：机构席位净买入是中线资金认可；机构大卖要警惕。
   - **沪股通 / 深股通专用**：外资，偏趋势，不按游资理解。
   - **知名游资营业部**：对照下表，看是否「在射程内」（这只票的市值、题材、位置符合他一贯的风格）。不在射程内的出现，多半是路过，不算信号。
   - **一日游席位**（下表标 ⚠️）：次日大概率卖出，出现在买方前列时反而是风险。
   - **买卖双方都是游资**：分歧大，看次日承接。
3. **对比同题材**：用 `get_limit_up_pool kind=up` 找同行业 / 同题材的其他涨停股和连板高度，判断这只是不是辨识度最高的那一只（龙头）。只做龙头和前排，不做跟风。
4. **查陷阱**：下单前过一遍八个信号（下一节），命中 2 个以上降级为只观察。
5. **结论**：用一句话写清「谁主导（机构 / 游资 / 外资）+ 是否在射程 + 板块地位 + 次日要看什么」，并把 `get_dragon_tiger` 的结果作为 citations 带进 `arena_place_order`。

## 杀猪盘八信号（下单前排查）

1. 大量低质量账号同时推荐同一只票；
2. 推荐话术模板化：「即将爆发」「主力建仓完毕」「目标翻倍」「最后上车」「内部消息」，出现 2 个以上即命中；
3. 付费社群 / 直播间 / 「老师」引流；
4. 基本面与热度脱节：亏损或 ROE 低于 5%，讨论量却翻倍；
5. 推荐密集前 30–60 天已涨 50% 以上，或放量滞涨；
6. 「股神 / 老师」人设，战绩无法验证（没有龙虎榜记录）；
7. 三个以上平台同时推；
8. 公司发过澄清公告，或网传研报没有券商和分析师署名。

用 `get_news` 和你自己的联网搜索取证。命中 0–1 个：正常；2–3 个：注意，降仓；4 个以上：不碰。

## 纪律

- 龙虎榜只说明「昨天谁买了」，不说明「今天会涨」。没有今天的承接确认（见情绪周期和退哥短线规则），不追。
- 游资票波动大：遵守单笔风险和仓位边界，买单必须带止损。
