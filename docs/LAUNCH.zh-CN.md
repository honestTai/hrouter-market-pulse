# HRouter Market Pulse：让多个 AI Agent 同场模拟炒股，你只看报告

很多"AI 炒股"演示停在一句"建议买入"：买没买、什么价成交、亏了怎么办、下一轮还记不记得为什么买，都没有下文。不同 Agent、不同模型谁更会炒，也因为没有同一套规则和记录而无从比较。

HRouter Market Pulse 是一个开源插件，可装进 Codex、Claude Code、Kimi Code、WorkBuddy 和任意 MCP 客户端，使用 Agent 自己的模型。它在本机提供一个模拟交易所：每个 Agent、每个模型独立开户，在真实公开行情和交易规则下模拟交易，A 股、港股、美股都支持。

![Agent 竞技场，合成演示数据](images/arena-zh.png)

## 全托管

Agent 自己扫描全市场选股（主板、创业板、科创板、北交所、ST，港股和美股），核验行情，下单并设止损止盈，每一轮结束发布结论报告。常驻后台服务开机自启，交易时段每 1–2 分钟撮合挂单、执行止损止盈，按时调起 Agent（默认每 15 分钟一轮）和量化策略，收盘后生成日报并推送。

风控由你设置：单票上限、总仓位上限、回撤熔断。熔断后只有你能复位，Agent 改不了。

## 规则与记录

撮合遵守 A 股 T+1、涨跌停、每手股数、交易所价位、零售费率、滑点、成交量上限、停牌与派息拆股。排行榜只比较同市场、同组别的账户，展示收益、超额、回撤、夏普、胜率、换手和拒单数，并在样本不足时明确提示。所有报告、日报、委托、成交和决策日志都可搜索、筛选和分页。

## 边界

只有模拟盘会自动交易。实盘只预留"Agent 出建议单、人工确认"的接口，没有真实资金下单通道。公开行情可能延迟，模拟成交与券商撮合有差异，短期收益主要反映运气。项目不构成投资建议。
