# 退哥短线规则

> 规则整理自 shouldnotappearcalm/a-share-skill 的 tuige-shortline-trading（MIT）：市场环境开关、选股、涨停回调、连板接力、失效和仓位纪律。原技能附带的 Python 脚本不随工作台分发；需要量化执行时，把规则写成你自己的代码策略（`arena_write_strategy`），上线前会自动回测。

## 1. 先定市场环境（总开关）

顺序：大盘 → 板块 → 个股，顺序不能反。用 `get_market_radar`（涨跌家数、涨停 / 炸板、主线板块）和 `get_limit_up_pool kind=emotion` 判断，给出一个标签：

| 标签 | 条件 | 允许的场景 |
|---|---|---|
| aggressive | 指数和主线共振，梯队完整 | 全部，包括接力 |
| rotation | 有轮动，主线不唯一 | 有辨识度的个股；不追最极端的 |
| pullback_only | 承接一般 | 只做回调确认、趋势回踩 |
| defensive | 指数弱，连续放量下跌 | 观察为主，轻仓试错 |
| no_trade | 指数、板块都不支持 | 空仓，只记录 |

环境不支持时，不能因为个股看起来强就放行。

## 2. 选股

- 先进股票池：流动性好（`scan_market` 按成交额），属于当日主线或有独立逻辑；
- 回避：ST、长期阴跌、利好兑现后高位放量滞涨、跟风后排；
- 强于指数、强于所属板块，才进候选。

## 3. 场景

### 涨停回调（pullback_only 以上可用）

- **三阴不破阳**：关键涨停阳线后连续调整，低点不破涨停阳线最低价；止跌后重新放量转强为触发；有效跌破该低点即失效。
- **涨停揉搓线**：涨停后冲高回落、探底回升反复试盘；揉搓结束重新转强为触发。
- **缩倍量回调**：涨停后缩量到涨停日一半以下回调，不破关键位；放量转强为触发。

### 连板接力（只在 aggressive 或强 rotation 可用，默认轻仓）

- **一进二**：强题材 + 强首板（早封、封单足、有辨识度）+ 次日竞价承接明确。次日弱承接或被同身位个股卡位即失效。
- **二进三**：二板有带动性，量能前缩后放；竞价或盘中资金继续选择它为触发。三板高开弱走、放量封不住、题材后排掉队即失效。
- **2+2**：两连板后两天断板整理，未破关键支撑，再次走强有承接为触发。整理中关键位失守或被新核心替代即失效。

共通检查：强题材、强卡位、强封板（坚决、封后承接稳）、竞价承接、板块共振。竞价承接不足、高开不转强、反复冲板不封、后排快速掉队，任何一条出现就按失效处理，不临时改成「波段」解释。

## 4. 失效与离场

- 结构失败（关键位跌破、接力不及预期）：当天离场，不补仓摊低；
- 趋势失效（跌破趋势参考均线并收不回）：离场；
- 兑现：高位放量滞涨、情绪进入高潮或退潮，分批兑现；
- 每笔买单都要写清 trigger、invalidation 和对应的止损价，并作为 `stopLossPrice` 带上。

## 5. 仓位纪律

| 等级 | 用于 | 参考仓位 |
|---|---|---|
| light | 接力、试错、环境 defensive | 单只不超过 10% |
| normal | 回调确认、趋势回踩 | 单只不超过 20% |
| heavy | 环境 aggressive 且主线龙头确认 | 单只不超过 30%，且受硬性边界约束 |

连续两笔失败后降一档；连续三笔失败停一天新开仓（与亏损熔断 skill 一致）。仓位上限永远以硬性边界为准。

## 输出要求

每只候选写：所属题材、当前结构（哪个场景）、入场依据、trigger、invalidation、卖出参考、风险、仓位等级。没有触发就不算买点。
